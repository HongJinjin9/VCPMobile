## 分类口径与最新范围

R/S/L/X 源自 2026-10-07 的命令研究，只描述迁移方式。当前范围由 [Phase 2 最新逐项审批](./phase-2/09-功能权限与提示审议表.md) 及主线 09 的沿革决定：分享、通知、相机、相册、网络遥测与 Distributed 已纳入接入方向；语音保留未开发说明，Root/APK 保留平台说明。不能用 X 类推导整个入口隐藏；本轮已将获批待接入的原生分支改为 `not_implemented`，不再用旧范围错误表示它们。

| 级别 | 语义处置 |
|---|---|
| `R` | 复用 Rust/跨平台路径，适配 cfg、路径与返回语义 |
| `S` | 需 Swift，Apple 公开 API 可实现接近当前目标 |
| `L` | 用 iOS 平台语义重新定义 DTO、生命周期或交互 |
| `X` | 该命令的系统机制属于 Android；iOS 不执行同名机制，入口是否保留说明按最新审批 |

- `permissions/all.toml` 与 `default.toml`：各 42；

相对旧 41 条：

## 消费导航与内部原生面

2026-10-07 抽取的 42 条 endpoint 消费分布保留为导航索引，当前新增/删除调用以生产代码为准：

| 分组 | 数量 | 解释 |
|---|---:|---|
| Vue IPC 消费 | 22 | 页面/Store/composable 直接 invoke |
| 仅 Rust 内部消费 | 11 | endpoint 本身无 Vue 调用，但底层 bridge 被 Chat/Sync/Lifecycle/Updater/Telemetry 使用 |
| 无生产消费者 | 9 | 逐项决定退役或由新增 iOS 调用者消费，例如前台常亮 |

同次抽取中 `guest-js/index.ts` 有 18 个 wrapper、17 个唯一命令，其中 9 个 wrapper 有生产调用；该统计不是每次阶段修改后的重计，也不是命令真源。

该次 Kotlin `VcpMobilePlugin` 抽取有 59 个 `@Command`，当前本轮未修改 Kotlin 注册面：

- 38 个由公开 Rust handler 桥接；
- 17 个 internal bridge：clipboard/local notification、按需 sensor、native Channel、CLI process/PTY、媒体处理；
- 2 个 screen command 实际被 Rust raw JNI 绕过；
- 2 个 overlay/floating command 已休眠且未注册。

平台审计同时覆盖以下内部入口：

- `registerNativeEvents`：已连接 Android/iOS 的 lifecycle/network Channel；Swift 订阅是内部接口，不依赖前端自有插件授权；
- `sampleSensorData`：Rust 内部按需采样；iOS 当前返回 `not_implemented`，模拟值仅留 host；后续按已批准的 Distributed 需求逐字段接入；
- clipboard/local notification：iOS 尚未接入，本轮分支明确返回 `not_implemented`；普通 Web Clipboard 复制是另一条共享路径；
- CLI/PTY/PRoot：保留 Android 路径，iOS bundle 资源清单单独列出；
- image/video/audio processors：iOS 图片/音频当前可进入小文件原样 Base64 回退，没有原生缩放/转码；视频仍延期；语音入口已保留未开发说明；
- updater、restart/exit、local loopback upload 和 app commands 中的 Android 语义。

## 同步平台身份与实际操作结果

原先的 `PlatformCapabilities`/24 项四字段状态表及查询链已删除，不再作为后续 DTO 要求。`src/core/utils/platform.ts` 用 `isTauri()` 区分普通预览，再同步读取 `@tauri-apps/plugin-os` 的 `platform()`，导出 `nativePlatform/isAndroid/isIOS`。启动无需 await 能力查询，Vue 在原功能 owner 内选择显示、说明或实际执行。

实际权限、当前连接、生命周期、后台任务和文件导出仍消费各自真实结果。例如同步读取 `BatteryStatusDto`，恢复读取 lifecycle phase/epoch，continued task 后续使用真实 attempt/task 与结果；这些领域状态不能由 OS 身份推断，也无需再汇总进一张平台能力表。更新、Root、语音的说明入口已接入；分享/通知/相机等原生功能仍按专项逐条实施。

## 当前 Tauri ACL 配置

Phase 1 已去掉 app 的 `vcp-mobile:allow-all` 引用并拆分 main 授权，不再有“待拆共享全量授权”的任务：

- `android-main.json` 显式列出前端消费的 22 条自有插件命令；
- `ios-main.json` 当前仅有 `core:default`、`opener:default`，自有插件前端授权为 0；
- `default.json` 的共同权限排除 iOS，只作用于 main；没有生产 portal 消费者或对应授权；
- OS 插件通过初始化脚本同步注入平台事实，此路径没有每次识别时的 IPC 请求；
- 自有插件内部 Rust→Swift Channel 不因存在原生 selector 就需要向 Vue 开放；未来新增实际前端调用时同步配置框架所需权限。

Tauri ACL 是框架调用配置，不承担功能审批。Vue 已能确定的说明入口直接说明并返回，Rust 保留实际输入、文件、任务和系统资源所需检查，不再复制一套跨平台功能门禁。

## 2026-10-07 分类口径

分类描述各命令的迁移方式；首期范围另见 09 的产品决定。

| 级别 | 语义处置 |
|---|---|
| `R` | 复用 Rust/跨平台路径，适配 cfg、路径与返回语义 |

| `X` | Android 专属命令，从 iOS 命令授权与 UI 入口中剔除 |

- 2 个 screen command 实际被 Rust raw JNI 绕过；

## 当前 Capability DTO 最小要求

以下是计划 DTO 的示例，表达软件已经接入后可能返回的状态。`support` 表示平台机制，`implementation` 表示本构建接入情况，`authorization` 表示用户授权，`runtime` 表示当前可用条件；研究记录在 00。示例中的 continued adapter 正在待实现阶段。

```json
{
  "platform": "ios",
  "osVersion": "26.5",
  "capabilities": {
    "chatForeground": {
      "support": "supported",
      "implementation": "implemented",
      "authorization": "not_applicable",
      "runtime": "available"
    },
    "chatContinuedProcessing": {
      "support": "supported",
      "implementation": "not_implemented",
      "authorization": "not_applicable",
      "runtime": "unavailable",
      "reasonCode": "ADAPTER_PENDING"
    },
    "notificationListener": {
      "support": "unsupported_by_platform",
      "implementation": "not_applicable",
      "authorization": "not_applicable",
      "runtime": "unavailable"
    }
  }
}
```

continued adapter 实现后，按 OS availability、用户任务与调度结果更新运行状态。系统是否接受某一次任务属于操作结果，由 `attemptId/taskId` 返回；capability 负责声明可发起的操作。

### 逐命令接入记录

对进入首期的 R/S/L 项补齐以下字段，形成可直接实现的映射：

| 项 | 内容 |
|---|---|
| 消费者 | Vue invoke 或 Rust 内部调用符号 |
| Rust 入口 | handler、参数与结果类型、序列化命名 |
| Native 入口 | Swift `@objc` selector、Decodable 字段、使用队列 |
| 生命周期 | callback/Channel 持有者、取消与最后一次释放 |
| 平台声明 | Info.plist 用途说明、ACL 和可选 entitlement |
| 完成条件 | 正常结果、拒绝、取消、重复/迟到回调的具体行为 |

## iOS ACL 裁决

当前 `capabilities/default.json` 的 `vcp-mobile:allow-all` 会作用于所有平台。施工时至少拆为：

- Android capability：继续承载当前正式功能；
- iOS capability：按当前实现及产品范围列举命令；
- `X` 归 Android；`L` 随 DTO/adapter 接入后加入 iOS allowlist；
- portal WebView 按自身实际消费者授予命令。

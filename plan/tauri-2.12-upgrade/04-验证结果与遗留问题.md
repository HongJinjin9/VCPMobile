## 3. Rust 17 项失败的基线对照

初次全量测试返回失败后，先在沙箱外重跑，17 项保持；随后运行本任务之前已编译的 Phase 2 测试程序 `vcp_mobile_lib-832998d85285cbac.exe`，同样为 **458 通过 / 17 失败**。最终 2.12.1 的失败名称集合与基线逐项相同。插件独立 12 项全部通过，workspace 合计 470 通过、17 个既有失败。

基线程序 SHA-256：`b4c78c5257adbc78165f8b703b4ece54c42caf63dc707697d55f467dc02746e2`。本地完整输出与比较报告保存在忽略目录 `temp/tauri-2.12-baseline-rust-tests.json`、`temp/tauri-2.12.1-current-rust-tests.json`；没有清空、跳过或改断言制造全绿结果。

| 类别 | 数量 | 已确认原因与处理 |
|---|---:|---|
| CLI ledger / output / projection / skill / runtime 目录同步 | 15 | Windows 打开/同步目录返回 os error 5；沙箱外也复现，原生产函数与本轮依赖升级无源码差异 |
| `manifest_matches_golden_snapshot_byte_for_byte` | 1 | fixture 包含 25 个 CRLF，serde pretty 输出为 LF；将预期的 CRLF 规范化后逐字相同。只作为根因证据，未修改测试或业务 |
| `traversal_and_symlink_entries_fail_before_catalog_mutation` | 1 | 既有断言要求错误字符串含 traversal，但基线与新版均失败；不借本轮升级改变错误协议或输入处理 |

这些历史结果能排除本轮新增该组失败，不能宣称 CLI 在 Windows 的这些路径本来就正确；host 是开发 scaffold，Android 行为仍以原 owner 与独立构建/验证为准。

## 4. Maven 访问受限与验证环境

首轮完整 Android build 在 Jackson 模块解析处收到 404。随后用 Maven 官方搜索 API 确认 `com.fasterxml.jackson.datatype:jackson-datatype-json-org:2.15.3` 已发布；直接下载入口连已知存在的 databind 也给出异常 404，并有长 Retry-After。这是当前出口访问限制，不能据此删除依赖或改用猜测的版本。[精确版本索引](https://search.maven.org/solrsearch/select?q=g:%22com.fasterxml.jackson.datatype%22%20AND%20a:%22jackson-datatype-json-org%22%20AND%20v:%222.15.3%22&rows=20&wt=json)

验证期间使用 Google Cloud 托管的公开 Maven Central 镜像。其主页明确表示不是 Google 正式支持产品；记录实际来源，不把它写成 Google 保证的服务。项目默认 Maven 仓库保持原配置。[镜像说明](https://storage-download.googleapis.com/maven-central/index.html)

最初临时规则仅覆盖 Jackson 的两个坐标，遗漏父 POM；补全后 AAR metadata 检查通过，但完整打包又请求其他 Central JAR。该过程说明元数据检查不能替代完整外部依赖解析。后续临时验证改为仅限本工作区替换 Maven Central URL，并在构建前一次解析 Debug compile/runtime/unit-test 的全部外部制品；Google Maven 和 JitPack 保持原配置。

本机还出现 Kotlin 增量编译的跨盘路径异常：registry 在 C 盘、工程在 G 盘。编译器已回退非 daemon；临时验证关闭 Kotlin incremental，避免反复读写该本机路径缓存，不修改生产 Gradle 属性或升级 Kotlin 来规避。

Robolectric 的 SDK 下载不属于 Gradle classpath 解析，临时配置同时将 Debug Test 的 `robolectric.dependency.repo.url` 指向该镜像；生产插件中原有地址保持。镜像仅替换同一 Maven Central 制品的下载入口，不调整依赖版本。

临时 init 只写到本机 Gradle 的唯一命名文件，使用 try/finally 在命令结束后校验哈希并删除。没有向 tracked 配置加入镜像，没有改 Cargo registry，没有使用发布签名或操作设备。

最终构建和 JVM 验证均成功，且已确认该临时 init 文件不存在。Debug APK 位于 `src-tauri/gen/android/app/build/outputs/apk/universal/debug/app-universal-debug.apk`，大小 70,365,468 字节，SHA-256 `8ee4c7e545bf04984162fa95e99b4e1c01b88ee7791533103807b6cad376136f`。ZIP 检查包含 11 个 native 文件，ABI 集合仅 `arm64-v8a`；aapt2 确认 Debug 包名、debuggable 与 targetSdk 36。

构建保留了已有 UnoCSS 三条未解析图标警告、上游/现有 Android deprecated API 与 Gradle 9 迁移提示。没有因此改 UI、升级 Gradle 或修改框架 registry；这些警告不作为“全量零警告”交付。

相对升级前快照，原 app build.rs 与六个 permission 文件哈希保持，carbon 依赖保持，npm 锁的非 Tauri 包集合/条目无变化。15 份本轮及关联文档的相对链接检查通过；Git 补丁空白检查通过。
